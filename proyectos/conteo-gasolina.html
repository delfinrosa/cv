Backend · Servidor de datos

Conteo Gasolina

Web API REST en C# sobre Ubuntu Server para analizar el consumo de combustible, con precios oficiales de la CRE y sincronización de datos desde el celular.

Aquí va una imagen
1200 × 800 px

Web API en Linux

  • Despliegue nativo en Ubuntu Server: la Web API de C# corre directamente en Linux, conectada a PostgreSQL en producción.
  • Arquitectura desacoplada: endpoints JSON, panel de administración y métricas separados de los servicios en segundo plano.
Aquí va una imagen
1200 × 800 px

Dapper y bases de datos

  • Un mismo código, dos motores: Dapper ejecuta consultas SQL optimizadas en SQL Server Express (pruebas en Windows/IIS) y en PostgreSQL (producción).

Precios oficiales de la CRE

  • Scraping automático: un servicio en segundo plano descarga y procesa los datos de la Comisión Reguladora de Energía para mantener actualizados los precios nacionales.
  • Contraste de precios: compara los precios oficiales con los consumos reales que reportan los usuarios para detectar variaciones.

Gasolineras cercanas

  • Búsqueda por GPS: cálculo por coordenadas para encontrar las gasolineras más cercanas, con sus precios actualizados y la última carga registrada.

Reportes e inteligencia de negocios

  • Gráficas de consumo: evolución del costo por litro y del kilometraje.
  • Exportación: reportes consolidados en CSV y Excel.

Sincronización offline-first

  • Datos sin conexión: endpoints que reciben los paquetes de datos generados en el celular sin internet y los integran al servidor central.
  • Sin bloqueos: la sincronización resuelve la consistencia de los datos sin afectar la disponibilidad de la API.
