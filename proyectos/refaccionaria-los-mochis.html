Refaccionaria Los Mochis

Plataforma integral de inventarios y ventas con backend centralizado en C#, app móvil en .NET MAUI y extensión de navegador.

Aquí va una imagen
1200 × 800 px

C# / .NET — el backend

  • Gestión de usuarios y contraseñas: con restricción de módulos por rol y expulsión automática del sistema al revocar permisos.
  • Reportes dinámicos: un reporteador hecho a medida que arma los reportes en tiempo real según lo que se necesite consultar.
  • Exportación a Excel: descarga de archivos Excel de ventas, catálogos y los distintos tipos de reportes.
  • Bot de Telegram: integración con la API de Telegram que consulta la base de datos para buscar números de parte específicos desde el chat.

.NET MAUI — la app móvil

Aplicación móvil nativa multiplataforma orientada a la movilidad en almacén, recepción de mercancía y gestión en piso de venta.

  • Seguridad y roles sincronizados: autenticación remota y restricción de pantallas/módulos por rol, replicando las políticas de acceso y expulsión del backend.
  • Consulta de precios y stock: búsqueda rápida de refacciones y verificación de existencias en tiempo real mediante consumo de la Web API.
  • Registro y altas de productos: formulario móvil para dar de alta nuevos artículos en el catálogo con actualización inmediata en la base de datos central.
  • Captura y gestión de imágenes: integración con la cámara del dispositivo para fotografiar refacciones, asociar imágenes al producto y subirlas al servidor.
  • Reportes móviles: visualización de métricas clave, resúmenes de inventario y reportes operativos optimizados para pantallas móviles.

Web API — servicios para la app móvil

API REST independiente creada para desacoplar la app móvil del backend MVC.

  • El problema: la app MAUI consumía directamente el backend MVC, el mismo que genera las vistas y atiende a los usuarios del sistema web todo el tiempo.
  • La solución: una Web API dedicada que expone los datos en JSON para la app, sin depender del backend de las vistas.
  • Resultado: carga separada entre la web y la app móvil; cada parte puede crecer o cambiar sin afectar a la otra.

Base de datos

Base de datos central del sistema, compartida por la web y la Web API.

  • Más de 25,000 productos registrados en el catálogo.
  • Más de 25 tablas relacionadas.
  • Control de stock: cantidad disponible de cada producto, con una vista que concentra las compras y las ventas.

Chrome Extension — consulta y automatización

Extensión de navegador que busca productos tanto en el sistema propio como en los sistemas de los proveedores, para consultar y después hacer pedidos.

  • Consulta de productos en el sistema propio: precio, disponibilidad, marca y descripción a partir de un número de parte o de una equivalencia.
  • Automatización de búsquedas: localiza productos en las páginas de los proveedores sin tener que buscarlos a mano en cada sitio.
  • Compras más ágiles: facilita los pedidos en los sistemas de otros proveedores.
